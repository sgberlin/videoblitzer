# Vercel Deployment Notes

Deploy `apps/web-app` to `app.videoblitzer.com` and `apps/marketing-site` to `videoblitzer.com` if Vercel is selected for marketing.

Frontend env vars must use publishable values only: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`, `NEXT_PUBLIC_API_URL`, `NEXT_PUBLIC_OWNER_EMAIL`, and `NEXT_PUBLIC_APP_NAME`.
