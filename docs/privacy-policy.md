# VideoBlitzer Privacy Policy

VideoBlitzer private beta access is email restricted. Recording happens locally when using the desktop app. Uploads happen only when a user chooses to upload source footage or exports.

Uploaded files are stored in Cloudflare R2. Supabase stores authentication records, profiles, projects, jobs, match data, usage, billing events, and contact messages. AI services may process audio, frames, metadata, captions, transcripts, and confirmed project data to generate content packs.

Users can delete projects and exports through the app once deletion workflows are enabled. Secret keys are never exposed in frontend code.
