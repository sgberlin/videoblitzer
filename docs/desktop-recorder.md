# VideoBlitzer Desktop Recorder

VideoBlitzer Recorder is an Electron MVP for recording actual screen/window video, saving WebM locally, uploading to VideoBlitzer through signed R2 URLs, and queuing backend MP4 conversion.

## Run Locally

```bash
npm install
npm --workspace @videoblitzer/desktop-recorder run build
npm --workspace @videoblitzer/desktop-recorder run dev
```

## Temporary Supabase Access Token

For the MVP, sign in to `https://app.videoblitzer.com` with your private-beta magic link. Open browser developer tools and copy the current Supabase access token from the Supabase auth session. Paste it into the recorder field labeled `Temporary access token for private beta testing`.

Do not share this token. The recorder only sends it as `Authorization: Bearer <token>` to the VideoBlitzer API.

## Record

1. Click `Select screen/window`.
2. Choose a source.
3. Choose recording quality: Standard, High, or Match Quality.
4. Optionally enable microphone audio.
5. Click `Start Recording`.
6. Click `Stop Recording`.
7. Confirm the WebM file path appears under Local file.

On macOS, if screen capture fails, enable Screen Recording in System Settings -> Privacy & Security -> Screen Recording, then restart VideoBlitzer Recorder.

## Upload

1. Confirm the API URL is `https://api.videoblitzer.com`.
2. Paste a Supabase access token.
3. Click `Upload to VideoBlitzer`.
4. The recorder creates a desktop-recorder project, requests a signed R2 `PUT` URL, uploads the WebM directly to R2, saves the video record, and queues MP4 conversion.
5. Open the project link in the web app.

## Formats

Raw capture format: WebM.

Preferred MIME order:

1. `video/webm;codecs=vp9,opus`
2. `video/webm;codecs=vp8,opus`
3. `video/webm`

Native `video/mp4` recording is shown only if Electron reports support. It is experimental and not required.

MP4 export is handled by backend FFmpeg conversion:

```bash
ffmpeg -i input.webm -c:v libx264 -preset veryfast -crf 23 -pix_fmt yuv420p -c:a aac -b:a 128k -movflags +faststart output.mp4
```

## Known Limitations

- WebM is the primary raw capture format.
- MP4 is generated by backend conversion.
- System audio support depends on operating system and source type.
- Full desktop login will replace temporary access-token auth later.
- Advanced job queue scaling is still a future production hardening step.

## Manual Test Checklist

1. Launch recorder.
2. Select screen/window.
3. Start recording.
4. Stop after 10 seconds.
5. Confirm WebM saved locally.
6. Open file locally.
7. Paste Supabase token.
8. Upload to VideoBlitzer.
9. Confirm signed URL created.
10. Confirm R2 PUT succeeds.
11. Confirm project/video record exists.
12. Confirm conversion job queued or MP4 conversion runs.
13. Confirm web app can show uploaded project.
